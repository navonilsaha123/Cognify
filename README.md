### 📖 GitHub Description (350 characters)

> **Cognify is an AI-powered learning and study assistant that helps students create personalized study plans, organize tasks, track academic progress, and manage assignments efficiently. Built with React, Node.js, Express, and MongoDB, it combines intelligent planning with a clean, responsive interface to improve productivity.**
